# ESC Easy Sensor Creation

Erstelle mühelos benutzerdefinierte Sensoren in Home Assistant!

## Features

- 🔋 **kWh Integration** - Power zu Energy Sensor
- ➕ **Summen-Sensor** - Mehrere Sensoren addieren
- 📊 **SQL Statistiken** - 14 verschiedene Statistik-Typen
- 🗄️ **SQLite + MariaDB** - Flexible Datenbank-Unterstützung

## Installation

1. Installiere über HACS
2. Starte Home Assistant neu
3. Füge die Integration hinzu
